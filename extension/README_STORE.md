# Weather Calendar Agent - Chrome Extension

## Overview

Weather Calendar Agent is a Chrome extension that automatically syncs weather forecasts to your Google Calendar, creating helpful alerts and suggestions based on upcoming weather conditions.

## Features

- 🌧️ **Rain Alerts** - Notifications for significant rainfall
- ❄️ **Snow Alerts** - Warnings about upcoming snowfall  
- 🌡️ **Temperature Alerts** - Extreme cold or heat warnings
- 💨 **Wind Alerts** - High wind condition notifications
- ☀️ **UV Alerts** - Sun protection reminders
- 🌤️ **Perfect Weather Suggestions** - Highlights ideal outdoor days

## Installation

1. Install from Chrome Web Store (link will be added after approval)
2. Click the extension icon
3. Authorize Google Calendar access
4. Enter your location and OpenWeatherMap API key
5. The extension will automatically sync every 15 minutes

## Requirements

- Google account with Calendar access
- Free OpenWeatherMap API key (get one at [openweathermap.org](https://openweathermap.org/api))
- Chrome browser

## Privacy

- All data stored locally
- No data collection
- Uses official Google OAuth
- Open source code
