# Extension Icon

You'll need to create one icon file for the extension:
- icon.png (128x128 pixels recommended)

You can create a simple weather-themed icon or use any icon you prefer. The extension will work without a custom icon, but Chrome will show a default icon.

For a quick solution, you can:
1. Use an online icon generator
2. Create a simple weather-themed icon (cloud, sun, etc.)
3. Use emoji as icon (🌤️, ☀️, etc.) converted to PNG
4. Use any 128x128 pixel PNG image
